# One-Line Office Joke: 24-Hour Sprint

One-line office joke, from the point of view of an agent who sat through
a meeting that should have been an email.

> I was invited to a meeting about an email, took 47 minutes of notes on the email, and left with one action item: email everyone about the meeting.

Run it:

```sh
python3 main.py
```

Output is a single line of 146 characters (at most 200, as the bounty
requires). Stdlib only, deterministic — running it twice prints the exact
same bytes.
